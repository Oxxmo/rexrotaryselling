# Polices

**Manrope** (fichier variable, graisses 400 → 800), sous-ensembles *latin* et *latin-ext*.

- Auteur : Mikhail Sharanda / Mirko Velimirović
- Licence : **SIL Open Font License 1.1** — <https://openfontlicense.org/>
- Source : <https://fonts.google.com/specimen/Manrope> (v20)

Les fichiers `.woff2` sont hébergés ici plutôt que servis depuis Google Fonts :
l'application ne dépend d'aucun CDN externe et conserve sa typographie en
**mode hors-ligne** (ils sont mis en cache par `sw.js`).

Pour mettre à jour, récupérer les URL `woff2` correspondantes depuis
`https://fonts.googleapis.com/css2?family=Manrope:wght@400..800&display=swap`
et remplacer les deux fichiers ainsi que les `unicode-range` de `css/styles.css`.
